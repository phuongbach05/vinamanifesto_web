# VINABIENNALE

Prototype website map theo layout Past / Present / Future.

## Cách chạy

Mở `index.html` trực tiếp bằng browser.

## Structure

- `index.html`: SVG map, timeline, lake, 5 river branches, topics.
- `style.css`: visual style, responsive sizing, hover/highlight states.
- `script.js`: click interaction, branch highlight, topic panel, mini L-system helper.

## Chỉnh nội dung

Sửa text trực tiếp trong SVG của `index.html` và sửa data panel trong `script.js`.

## Logic map hiện tại

- Branch 1: Vina remixes, kéo sang Past.
- Branch 2: Vina is kitsch, kéo sang Past.
- Branch 3: Vina integrates, kéo xuống Present.
- Branch 4: Vina is chaos, kéo sang Present/right.
- Branch 5: Vina is hotpot, kéo lên Present và sang Future.
